Measured detection, model-backed classifiers, MCP lifecycle helpers and typed metadata.

- Detection benchmark: a labelled corpus of 705 attacks and benign look-alikes in `bench/`, with catch-rate and false-alarm floors that run in CI. The threat model page lists held-out results per detector.
- Stronger offline detectors: prompt-injection signals that check decoded and de-obfuscated text and override phrases in ten languages; phrase-level toxicity; IBAN, international phone, address and spelled-out email PII; secret detection that skips hashes and placeholders; MCP exfiltration checks.
- `promptInjectionDetector` reads tool results, covering indirect injection on every agent step. New `mcpToolResultGuardrail()` scans the tool results each step adds.
- Model-backed detectors: `classifierGuardrail()` and `classifierOutputGuardrail()`, with `llmClassifier()`, `openAIModerationClassifier()`, `presidioClassifier()` and `huggingFaceClassifier()`.
- `guardMcpTools()` scans an MCP tool set and its input schemas, enforces an allowlist and pins definitions.
- Policy packs: `piiPack()`, `mcpHardenedPack()`, `evalSandboxPack()`.
- `retryAfterIntegration()` reads `retry-after` and `x-ratelimit-*` headers. `intentBasedInjectionDetector()` uses intent cues in its verdict.
- Typed metadata: `GuardrailMetadata` and `MetadataValue` describe JSON-valued metadata; `GuardrailContext` has named fields, including `metadata` and `openaiApiKey`. See "Upgrading to v7" in the README.
- `./config`: LLM rails receive `ctx.llm`, `Moderation` calls the OpenAI Moderation API, rails without a verdict block and report `executionFailed`, and `validatePipelineConfig()` reports unknown guardrail names.
- Stream transforms type as `StreamTextTransform` and work with `streamText`. Mixed output guardrails, typed tool-parameter guardrails, `retryHelpers`, `createGuardrailPrepareStep()` and `wrapToolWithAbortion()` compile with AI SDK 7 types. Finish-reason helpers use AI SDK 7 values. Retry callbacks receive an `Error`.
- Peer ranges: `ai` `^7.0.163`, `@opentelemetry/api` `^1.10.0`.
